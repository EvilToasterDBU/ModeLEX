# HTML-обои для ModLEX

Обои — один самодостаточный `.html` (CSS/JS/библиотеки внутри файла). Выбирается в
**Настройки → ModLEX → Фон лаунчера** так же, как картинка или видео.

Примеры: [`snow.html`](snow.html) (снег, отталкивается от курсора), [`cube3d.html`](cube3d.html)
(3D-куб, следует за курсором), [`paper-cards.html`](paper-cards.html) (карточки лаунчера наклоняются
от курсора, как листки в воздухе; подсказка раскладки и палитра).

## Песочница

Страница запускается в `<iframe sandbox="allow-scripts">` **без** `allow-same-origin`:

- нет доступа к данным лаунчера, аккаунтам, файлам и Tauri API;
- нет `localStorage`/cookies родителя (у страницы «пустой» origin);
- сеть не нужна и на неё не рассчитывай — кладите библиотеки (three.js и т.п.) прямо в файл;
- обои получают данные от лаунчера, а обратно могут слать только **данные из короткого списка** (см.
  «Сообщения от обоев»): всё остальное лаунчер молча игнорирует.

## Сообщения от лаунчера

Все приходят через `window.addEventListener('message', e => ...)`, у каждого `e.data.source === 'modlex'`.

| `type`    | Поля                                                            | Когда |
|-----------|-----------------------------------------------------------------|-------|
| `resize`  | `width`, `height` (CSS-пиксели)                                 | после загрузки и при каждом изменении размера окна |
| `theme`   | `accentColor` (`#rrggbb` или `null`)                            | после загрузки и при смене акцентного цвета |
| `state`   | `paused`, `reason` (`user`/`game`/`blur`/`null`), `fpsLimit`, `volume` (0..1) | при изменениях: выключена анимация, идёт игра, окно без фокуса |
| `pointer` | `kind` (`move`/`down`/`up`), `x`, `y`, `buttons`, `width`, `height` | движение мыши и клики над окном лаунчера |
| `cards`   | `cards[]`: `id`, `kind` (`library`/`jumpin`), `x`, `y`, `w`, `h`, `hover` | только после `subscribe`; при каждом изменении положения/размера карточек и наведения |

`pointer` приходит в координатах iframe — потому что слой обоев лежит под интерфейсом и сам
событий мыши не получает. `move` объединяется по кадрам.

## Сообщения от обоев

Обои шлют `parent.postMessage({ source: 'modlex-wallpaper', type: ..., ... }, '*')`. Лаунчер принимает
сообщения только от своего iframe, проверяет каждое поле и всё лишнее отбрасывает.

| `type`                   | Поля | Что делает |
|--------------------------|------|------------|
| `subscribe`              | `cards: true/false` | включает/выключает рассылку `cards`. Без подписки лаунчер карточки не измеряет |
| `palette`                | `accent`: `#rrggbb` | цвет для тумблеров «Акцент/Вся тема под обои» (у HTML-обоев лаунчер пиксели прочитать не может) |
| `layout`                 | `layout`: `{ showJumpIn, showLibrary, showLibrarySearch, cardSize: small/medium/large, jumpInSize: compact/normal }` — любые поля | подсказка раскладки главной. Настройки пользователя не перезаписываются: в настройках появляется тумблер «Раскладка из обоев», выключив его пользователь возвращает своё. Действует, пока активны эти обои |
| `card-transforms`        | `items`: `[{ id, rx, ry, tz, s }]` | наклон карточек: `rx`/`ry` в градусах (−45…45), `tz` в px (−100…100), `s` масштаб (0.8…1.2). Работает только после `subscribe`; до 300 карточек за сообщение |
| `card-transforms-clear`  | — | вернуть все карточки в исходное положение |

Карточки не перекрашиваются и не подменяются: обои управляют только их `transform` в этих пределах.
Наклоны сами сбрасываются, когда анимация обоев выключена, обои сменились или отписались.
`id` карточки берётся из сообщения `cards` и заведомо уникален (`lib:…` — библиотека, `jump:…` — Jump in).
Присылай наклоны только когда они меняются — не шли одни и те же данные каждый кадр без нужды.

### Звук

Если обоям нужен звук — играй его с громкостью `volume` (по умолчанию 0.3, пользователь меняет в
настройках) и **молчи, пока `paused`**: игра, неактивное окно и выключенная анимация тоже означают тишину.
Браузер может не разрешить звук до первого действия пользователя — это нормально, начни играть после
первого `pointer` `down`.

### Обязательно уважай `state`

Пока `paused === true` — **не рисуй и не считай** (просто `return` в цикле `requestAnimationFrame`),
это экономит GPU, пока идёт игра или окно свёрнуто. `fpsLimit` — желаемый максимум кадров в секунду.

## Минимальный шаблон

```html
<canvas id="c"></canvas>
<script>
  const state = { paused: false, fpsLimit: 60 }
  addEventListener('message', (e) => {
    const m = e.data
    if (!m || m.source !== 'modlex') return
    if (m.type === 'state') Object.assign(state, m)
    if (m.type === 'pointer') { /* m.x, m.y */ }
  })
  function frame() {
    requestAnimationFrame(frame)
    if (state.paused) return
    // ...рисуем
  }
  frame()
</script>
```
